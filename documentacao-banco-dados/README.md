# Banco de dados

Esta pasta contem a documentacao e o script completo do banco de dados:

- `DER-Projeto-Filmes.png`: diagrama entidade-relacionamento em imagem.
- `DER.md`: versao editavel do diagrama em Mermaid.
- `script_sql_completo.sql`: script completo com
  `CREATE TABLE`, relacionamentos e `INSERTs` para testes.

O modelo apresentado descreve um catalogo de filmes com usuarios, generos,
avaliacoes e favoritos. Nao existem entidades ou funcionalidades de locacao.
