# Perfil Usuario

Esta pasta organiza a area do usuario comum do frontend.

No momento, a area do usuario continua dentro de `frontend/index.html`, `frontend/styles.css` e `frontend/script.js` para manter compatibilidade com o deploy atual.

## Onde esta cada parte hoje

- HTML: secao `appShell` em `../index.html`
- CSS: estilos da area do usuario em `../styles.css`
- JavaScript: navegacao, catalogo publico e detalhes de filmes em `../script.js`

## Telas do usuario

- Inicio
- Filmes
- Detalhes do filme
- Favoritos
- Assistidos
- Perfil

## Observacao

Esta pasta funciona como uma gaveta de organizacao. Ela nao muda rotas, banco, Render, Railway ou GitHub Actions.
